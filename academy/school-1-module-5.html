Module 5: Customs

ระดับเริ่มต้น
เป้าหมายของโมดูล
ผู้เรียนเข้าใจระบบพิกัดศุลกากรและขั้นตอนพิธีการศุลกากรทางอิเล็กทรอนิกส์ครบวงจร

5.1 HS Code

ระบบพิกัดอัตราศุลกากร (Harmonized System) ใช้จำแนกประเภทสินค้าเพื่อกำหนดอัตราอากรและข้อกำหนดการนำเข้า ตรวจสอบได้จากฐานข้อมูลพิกัดอัตราศุลกากรของกรมศุลกากร หรือสอบถาม Call Center กรมศุลกากร 1164 ยืนยันแล้ว

แหล่งอ้างอิง: กรมศุลกากร

5.2 Tariff (อัตราอากร)

อัตราอากรขาเข้าตาม HS Code แต่ละรายการแตกต่างกัน มีทั้งอัตราปกติ (General Rate) และอัตราพิเศษภายใต้ความตกลงการค้าเสรี (FTA Rate) ซึ่งต้องใช้ Certificate of Origin ประกอบการขอใช้สิทธิ ต้องตรวจสอบเพิ่มเติม

แหล่งอ้างอิง: กรมศุลกากร, กรมการค้าต่างประเทศ — ต้องเช็คเป็นรายสินค้าและรายประเทศ

5.3 Customs Declaration

การยื่นใบขนสินค้าขาเข้าผ่านระบบอิเล็กทรอนิกส์ของกรมศุลกากร โดยตัวแทนออกของหรือผู้นำเข้าเองต้องลงทะเบียน Digital ID ล่วงหน้า

5.4 Customs Inspection

ระบบประเมินความเสี่ยงจะสุ่มตรวจใบขนสินค้า หากเข้าเกณฑ์ตรวจสอบ (Red Line) เจ้าหน้าที่จะตรวจสอบเอกสารและ/หรือเปิดตรวจสินค้าจริง หากไม่เข้าเกณฑ์ (Green Line) จะได้รับการปล่อยผ่านโดยไม่ต้องตรวจเพิ่มเติม

5.5 Clearance Process

ขั้นตอนพิธีการศุลกากรทางอิเล็กทรอนิกส์ 5 ขั้นตอน ได้แก่ (1) จัดทำใบขนสินค้าขาเข้า (2) ตัดบัญชีใบขนสินค้ากับรายงานยานพาหนะ (3) ชำระค่าภาษีอากร (4) ตรวจสอบตามกระบวนการศุลกากร (5) รับของออกจากอารักขาศุลกากร ยืนยันแล้ว

แหล่งอ้างอิง: คู่มือการผ่านพิธีการศุลกากรทางอิเล็กทรอนิกส์ กรมศุลกากร
