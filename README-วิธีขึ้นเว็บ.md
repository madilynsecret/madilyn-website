# วิธีขึ้นเว็บไซต์ใหม่ — Madilyn's Secret

โฟลเดอร์นี้คือเว็บไซต์ทั้งเว็บ ไม่ต้องติดตั้งอะไรเพิ่ม ลากขึ้นโฮสต์ได้เลย

```
madilyn-website/
├─ index.html      ← ทั้งเว็บอยู่ในไฟล์เดียว (HTML + CSS + JS)
├─ favicon.svg     ← ไอคอนบนแท็บเบราว์เซอร์
└─ og-image.png    ← รูปที่ขึ้นตอนแชร์ลิงก์ใน Facebook / LINE
```

---

## เลือกโฮสต์

| ตัวเลือก | ค่าใช้จ่าย | เหมาะกับ | ข้อเสีย |
|---|---|---|---|
| **Cloudflare Pages** ← แนะนำ | ฟรี ตลอด (จ่ายแค่ค่าโดเมนปีละ ~400–600฿) | เว็บนี้พอดีเลย เร็วมาก แบนด์วิดท์ไม่จำกัด SSL ฟรี | แก้เนื้อหาต้องแก้ไฟล์แล้วอัปใหม่ |
| Netlify / Vercel | ฟรี (แบนด์วิดท์ 100GB/เดือน) | เหมือนกัน แต่มีลิมิตทราฟฟิก | ลิมิตแบนด์วิดท์ |
| WordPress + โฮสต์ไทย | ~150–400฿/เดือน | ถ้าอยากเขียนบทความเองบ่อย ๆ ผ่านหน้าจอ | ช้ากว่า ต้องอัปเดตปลั๊กอิน เสี่ยงโดนแฮก |
| Wix (ของเดิม) | ~300–900฿/เดือน | ใช้ต่อได้ถ้าไม่อยากย้าย | แพงสุด โหลดช้าสุด SEO สู้ static ไม่ได้ |

**เหตุผลที่แนะนำ Cloudflare Pages:** เว็บนี้เป็นไฟล์เดียว โหลดเสร็จในพริบตา
ซึ่ง Google ใช้ความเร็วเป็นสัญญาณจัดอันดับ และคนไทยส่วนใหญ่เปิดจากมือถือผ่าน 4G
เว็บที่โหลดช้าเกิน 3 วินาทีคนกดปิดก่อนเห็นปุ่มขอใบเสนอราคา

## ขั้นตอนขึ้นเว็บ (ประมาณ 20 นาที)

### 1. เตรียมโดเมน
คุณมี `madilynsecret.com` อยู่แล้ว ให้ดูว่าจดไว้ที่ไหน (ผู้ให้บริการเดิม)
ถ้ายังไม่มีหรืออยากย้าย จดที่ Cloudflare Registrar ได้ ราคาต้นทุนไม่บวกกำไร

### 2. สมัคร Cloudflare
สมัครฟรีที่ cloudflare.com → เพิ่มโดเมน → ระบบจะให้ nameserver 2 ตัว
เอาไปใส่ที่ผู้รับจดโดเมนเดิม รอ DNS อัปเดตประมาณ 1–24 ชม.

### 3. อัปโหลดเว็บ
เข้า Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** →
**Upload assets** → ลากโฟลเดอร์ `madilyn-website` ทั้งโฟลเดอร์เข้าไป → Deploy
(ไม่ต้องใช้ GitHub ไม่ต้องเขียนโค้ด)

### 4. ผูกโดเมน
ในโปรเจกต์ Pages → **Custom domains** → **Set up a domain** → ใส่ `madilynsecret.com`
และ `www.madilynsecret.com` → SSL ติดตั้งอัตโนมัติ

### 5. ต่อฟอร์มให้ส่งเข้าอีเมลจริง
ตอนนี้ฟอร์มทั้งสองอันยังไม่ส่งไปไหน (`action="#"`) เลือกวิธีใดวิธีหนึ่ง:

- **Formspree** (ฟรี 50 ข้อความ/เดือน) — สมัคร formspree.io แล้วเอา URL ที่ได้
  ไปแทนที่ `action="#"` ทั้ง 2 จุดในไฟล์ `index.html`
- **Google Forms** — สร้างฟอร์ม แล้วเปลี่ยนปุ่มเป็นลิงก์ไปยังฟอร์มแทน

ค้นคำว่า `action="#"` ในไฟล์จะเจอทั้ง 2 จุด มีคอมเมนต์กำกับไว้แล้ว

### 6. เก็บสถิติ
ใน Cloudflare มี **Web Analytics** ฟรี เปิดได้เลย ไม่ต้องใส่โค้ด
ไม่ใช้คุกกี้ ไม่ต้องขึ้นแบนเนอร์ขอความยินยอม

## หลังขึ้นเว็บแล้วควรทำ

1. ส่ง sitemap เข้า Google Search Console (ยืนยันความเป็นเจ้าของผ่าน Cloudflare ได้ในคลิกเดียว)
2. อัปเดตลิงก์เว็บไซต์ในเพจ Facebook, Instagram, LINE OA และ Google Business Profile
3. ถ้าจะปิด Wix เดิม ให้ตั้ง redirect จาก URL เก่าไปหน้าใหม่ก่อน อย่างน้อย 3 เดือน
   ไม่งั้นอันดับ Google ที่สะสมไว้จะหายไปด้วย

## จุดที่ตั้งใจออกแบบมาเพื่อดึง Lead

- **ตัวเลือกเส้นทาง** ด้านบน — ให้คนกดดูเส้นทางตัวเอง แล้วปุ่มขอใบเสนอราคา
  จะเลือกเส้นทางนั้นให้อัตโนมัติในฟอร์มด้านล่าง ลดแรงเสียดทาน
- **ฟอร์มถามแค่ 3 อย่าง** — สินค้าอะไร เท่าไร ส่งไปไหน ยิ่งถามน้อยยิ่งได้ lead เยอะ
- **แถบปุ่มติดล่างจอบนมือถือ** — โทร กับ ขอใบเสนอราคา อยู่ในนิ้วโป้งตลอดเวลา
- **FAQ** — เขียนด้วยคำที่คนไทยพิมพ์ค้นจริง ๆ ("ต้องจดบริษัทก่อนไหมถึงจะนำเข้าได้")
  เป็นตัวดึงคนจาก Google ที่ทำงานให้เรื่อย ๆ โดยไม่ต้องจ่ายค่าโฆษณา
- **ช่องรับอีเมล Academy** — เปลี่ยนคนที่ยังไม่พร้อมจ้าง ให้กลายเป็นรายชื่อ
  ที่ขายอีบุ๊กและคอร์สได้ทีหลัง

## ข้อควรระวังด้านเนื้อหา

- ตัวเลขในหน้าเว็บใช้เฉพาะที่ยืนยันได้ (ปีจดทะเบียน จำนวนสำนักงาน เลขทะเบียนนิติบุคคล)
  ไม่มีการอ้างจำนวนลูกค้าหรือปริมาณตู้ที่ยังไม่มีหลักฐาน — ถ้ามีตัวเลขจริงค่อยเติมทีหลัง
- ส่วนเนื้อหาความรู้มีข้อความกำกับว่าเป็นข้อมูลเพื่อการศึกษา ไม่ใช่คำวินิจฉัยทางกฎหมาย
- ส่วน DDP ระบุชัดว่าจะแจ้งว่าใครเป็นผู้นำเข้าของตามกฎหมาย ซึ่งเป็นจุดที่ควรพูดให้ตรง
