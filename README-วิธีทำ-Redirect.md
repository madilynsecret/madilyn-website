# วิธีทำ Redirect ตอนย้ายจาก Wix

## ก่อนอื่น — ต้องรู้ว่าเว็บเดิมของคุณเป็นแบบไหน

เปิดเว็บเดิมแล้วดูช่อง URL ด้านบน

**แบบ ก. เห็นเป็น `minimoolek.wixsite.com/madilynsecret`**
คือแพ็กเกจฟรีของ Wix → **ทำ 301 redirect ไม่ได้** Wix ระบุชัดว่าเปลี่ยนเส้นทางจาก URL ฟรีไม่ได้
ต้องอัปเกรดเป็น Premium และผูกโดเมนก่อนถึงจะใช้เครื่องมือ redirect ได้
→ ข้ามไปอ่าน **วิธีที่ 1**

**แบบ ข. เห็นเป็น `madilynsecret.com`**
คือมี Premium และผูกโดเมนไว้แล้ว → ทำ redirect ได้เต็มรูปแบบ
→ ข้ามไปอ่าน **วิธีที่ 2**

---

## ข่าวดีก่อนเริ่ม

รอบที่แล้วฉันเตือนว่าถ้าไม่ทำ redirect อันดับ Google จะหายหมด — ขอแก้ให้ถูกต้อง

ถ้าเว็บเดิมเป็น **แบบ ก. (wixsite.com ฟรี)** ความเสียหายน้อยกว่าที่บอกไว้มาก
เพราะ URL แบบนั้นเป็นแค่โฟลเดอร์ย่อยบนโดเมนของ Wix เอง อันดับที่สะสมได้จะน้อยอยู่แล้ว
สิ่งที่ต้องกังวลจริง ๆ ไม่ใช่ Google แต่คือ **ลิงก์เก่าที่คุณแปะไว้ตามที่ต่าง ๆ**
— เพจ Facebook, IG bio, LINE OA, นามบัตร, ใบเสนอราคาเก่า, กลุ่มไลน์ลูกค้า

---

## วิธีที่ 1 — เว็บเดิมเป็น Wix ฟรี (ทำได้เท่านี้)

### 1. เปลี่ยนหน้าแรกเว็บเดิมเป็นป้ายบอกทาง
เข้า Wix Editor → ลบเนื้อหาหน้าแรกออก → ใส่แค่นี้

> **เราย้ายเว็บไซต์แล้ว**
> เข้าที่ madilynsecret.com
> [ปุ่ม: ไปยังเว็บไซต์ใหม่]

ตั้งปุ่มให้ลิงก์ไปเว็บใหม่ **เปิดในแท็บเดิม** ไม่ใช่แท็บใหม่

### 2. อย่าเพิ่งลบเว็บเดิม
ปล่อยหน้าป้ายบอกทางไว้อย่างน้อย **6 เดือน** ไม่มีค่าใช้จ่ายเพราะเป็นแพ็กเกจฟรีอยู่แล้ว

### 3. ไล่เปลี่ยนลิงก์ทุกที่ — ข้อนี้สำคัญที่สุด
- เพจ Facebook → แก้ช่องเว็บไซต์ + ปุ่ม Call to Action
- Instagram → แก้ลิงก์ใน bio
- LINE OA → แก้ลิงก์ในเมนูริชเมนู
- **Google Business Profile** → แก้ช่องเว็บไซต์ (ข้อนี้ส่งผลกับการค้นหาแบบ "ชิปปิ้ง ใกล้ฉัน" มากที่สุด)
- ลายเซ็นอีเมล นามบัตร ใบเสนอราคา แคตตาล็อก

### 4. บอก Google ว่ามีเว็บใหม่
สมัคร Google Search Console ฟรี → เพิ่ม `madilynsecret.com` →
ยืนยันความเป็นเจ้าของ (ถ้าใช้ Cloudflare จะกดยืนยันได้ในคลิกเดียว) →
เมนู Sitemaps → ใส่ `sitemap.xml` → Submit

## วิธีที่ 2 — เว็บเดิมใช้โดเมน madilynsecret.com อยู่แล้ว

**จุดที่คนพลาดบ่อย:** พอย้าย nameserver ของโดเมนไป Cloudflare แล้ว
Wix จะไม่ได้เป็นคนเสิร์ฟเว็บอีกต่อไป → **ตั้ง redirect ใน Wix ไปก็ไม่ทำงาน**
ดังนั้น redirect ต้องไปอยู่ที่ **Cloudflare** ซึ่งฉันเตรียมไฟล์ให้แล้ว

### 1. เก็บรายชื่อ URL เก่าก่อนย้าย (ทำก่อนเสมอ)
เลือกวิธีใดก็ได้
- ค้นใน Google ว่า `site:madilynsecret.com` แล้วจดทุก URL ที่ขึ้นมา
- หรือเข้า Google Search Console เดิม → Pages → Export
- หรือเปิด `madilynsecret.com/sitemap.xml` แล้วก๊อปรายการออกมา

### 2. จับคู่ URL เก่ากับจุดใหม่
เว็บใหม่เป็นหน้าเดียว ทุกอย่างจึงชี้ไปที่จุดยึด (anchor) บนหน้าเดียวกัน

| หน้าเก่า | ไปที่ |
|---|---|
| /about, /services | `/#services` |
| /contact | `/#quote` |
| /faq | `/#faq` |
| หน้าเนื้อหา/บทความ | `/#academy` |
| อื่น ๆ ทั้งหมด | `/` |

### 3. แก้ไฟล์ `_redirects`
ในโฟลเดอร์เว็บมีไฟล์ชื่อ `_redirects` อยู่แล้ว เปิดด้วย Notepad หรือ TextEdit
แก้ทางซ้ายให้ตรงกับ URL จริงที่จดมาจากข้อ 1

```
/ทางเก่า    /ทางใหม่    301
```

บรรทัดสุดท้าย `/*  /  301` คือตาข่ายกันตก — URL เก่าอันไหนที่ลืมใส่
จะถูกส่งไปหน้าแรกแทนที่จะขึ้น 404

⚠️ ไฟล์ต้องชื่อ `_redirects` เป๊ะ ๆ มีขีดล่างนำหน้า **ไม่มีนามสกุล .txt**
ถ้า Windows เติม .txt ให้อัตโนมัติ ให้เปิด "แสดงนามสกุลไฟล์" แล้วลบออก

### 4. อัปโหลดทั้งโฟลเดอร์ขึ้น Cloudflare Pages
Cloudflare จะอ่านไฟล์ `_redirects` เองอัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม

### 5. ย้าย nameserver ของโดเมนมาที่ Cloudflare แล้วผูก custom domain
ทำตามขั้นตอนใน README-วิธีขึ้นเว็บ

### 6. ทดสอบว่า redirect ทำงาน
เปิด `madilynsecret.com/about` ในเบราว์เซอร์ →
ต้องเด้งไปหน้าใหม่ทันทีและ URL เปลี่ยนเป็น `madilynsecret.com/#services`

ถ้าอยากเช็กว่าเป็น 301 จริงไม่ใช่ 302 ให้ใช้เว็บเช็กฟรี ค้นคำว่า "301 redirect checker"

### 7. แจ้ง Google
Search Console → เพิ่มโดเมน → Sitemaps → ใส่ `sitemap.xml`
Google จะค่อย ๆ ย้ายอันดับตามเอง ใช้เวลาประมาณ 2–8 สัปดาห์ อย่าเพิ่งตกใจถ้าอันดับแกว่ง

## เรื่องอีเมลบริษัท — อย่าลืม

ถ้า `import-export@madilynsecret.com` ใช้งานอยู่ ตอนย้าย nameserver
**ต้องคัดลอก MX record เดิมมาใส่ใน Cloudflare ด้วย** ไม่งั้นอีเมลจะเข้าไม่ได้

วิธีเช็ก: ก่อนย้าย ให้เข้าไปดูหน้า DNS ของผู้ให้บริการเดิม แคปหน้าจอเก็บไว้ทุก record
แล้วใส่กลับให้ครบใน Cloudflare — โดยเฉพาะ MX และ TXT

## ไฟล์ที่เพิ่มให้ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `_redirects` | ตารางเปลี่ยนเส้นทาง Cloudflare อ่านอัตโนมัติ |
| `sitemap.xml` | แผนผังเว็บสำหรับส่งเข้า Google |
| `robots.txt` | บอกบอตว่าเก็บข้อมูลได้ และ sitemap อยู่ไหน |

ทั้งสามไฟล์เขียน `madilynsecret.com` ไว้ ถ้าโดเมนจริงไม่ใช่ชื่อนี้ ให้แก้ให้ตรงก่อนอัปโหลด
