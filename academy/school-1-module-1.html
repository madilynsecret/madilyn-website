Module 1: Introduction to Import

ระดับเริ่มต้น
เป้าหมายของโมดูล
ผู้เรียนเข้าใจนิยาม บทบาทของผู้นำเข้า สิ่งที่ต้องเตรียมก่อนเริ่ม และภาพรวมกระบวนการนำเข้าทั้งระบบ

1.1 Import คืออะไร

การนำเข้า (Import) คือการนำสินค้าจากต่างประเทศเข้ามาในราชอาณาจักรไทยเพื่อจำหน่ายหรือใช้งาน ซึ่งอยู่ภายใต้การกำกับดูแลของพระราชบัญญัติศุลกากร พ.ศ. 2560 สินค้าทุกรายการที่ผ่านเข้าประเทศต้องผ่านพิธีการศุลกากรก่อนจึงจะออกจากอารักขาของกรมศุลกากรได้ ยืนยันแล้ว

แหล่งอ้างอิง: พระราชบัญญัติศุลกากร พ.ศ. 2560, กรมศุลกากร

1.2 ใครคือ Importer

ผู้นำเข้าคือบุคคลธรรมดาหรือนิติบุคคลที่ลงทะเบียนเป็นผู้ผ่านพิธีการศุลกากรทางอิเล็กทรอนิกส์กับกรมศุลกากร โดยต้องมีเลขประจำตัวผู้เสียภาษีและลงทะเบียน Digital ID กับกรมศุลกากรก่อนจึงจะยื่นใบขนสินค้าขาเข้าได้ ยืนยันแล้ว

1.3 Importer ต้องเตรียมอะไรก่อนเริ่มนำเข้า

  • จดทะเบียนนิติบุคคลหรือบุคคลธรรมดาให้พร้อมออกใบกำกับภาษี
  • ลงทะเบียนผู้ผ่านพิธีการศุลกากรทางอิเล็กทรอนิกส์ (e-Customs) กับกรมศุลกากร
  • ตรวจสอบพิกัดศุลกากร (HS Code) ของสินค้าที่จะนำเข้า
  • ตรวจสอบว่าสินค้าต้องขอใบอนุญาตจากหน่วยงานควบคุมอื่นหรือไม่ (ดู School 4)

1.4 ขั้นตอนนำเข้าสินค้าทั้งระบบ

กรมศุลกากรกำหนดขั้นตอนพิธีการนำเข้าทางอิเล็กทรอนิกส์ไว้ 5 ขั้นตอนหลัก ได้แก่ (1) จัดทำและยื่นใบขนสินค้าขาเข้า (2) ตัดบัญชีใบขนสินค้ากับรายงานยานพาหนะ (3) ชำระค่าภาษีอากร (4) ตรวจสอบตามกระบวนการศุลกากร (5) รับสินค้าออกจากอารักขาศุลกากร ยืนยันแล้ว

แหล่งอ้างอิง: คู่มือการผ่านพิธีการศุลกากรทางอิเล็กทรอนิกส์ กรมศุลกากร

1.5 Flow การนำเข้าสินค้า

วิจัยสินค้าและซัพพลายเออร์ → ตกลงราคาและเงื่อนไข Incoterms → จองระวางขนส่ง → เตรียมเอกสารนำเข้า → สินค้าถึงท่าหรือด่าน → ยื่นใบขนสินค้าขาเข้า → ชำระภาษีอากร → ตรวจปล่อยสินค้า → รับสินค้าเข้าคลัง
